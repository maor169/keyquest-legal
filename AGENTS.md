# KeyQuest Studio Legal Pages

## What this is
Public static support and privacy pages hosted by GitHub Pages at `https://maor169.github.io/keyquest-legal/`. Each app has a separate directory and its own logo and factual privacy description.

## Build and release
There is no build step. Preview HTML locally, run the available link/content checks, then push the reviewed static files to `main`; GitHub Pages deploys from the root of that branch.

## Conventions and decisions
- Keep each app's claims tied to its current source and enabled services; update policies before publishing changed data practices.
- Use the matching app/game logo and preserve its source provenance. Do not reuse another app's art.
- Do not add analytics, advertising scripts, cookies, forms, or third-party fonts to these pages.
- The root index may list each app's support and privacy pages. Use the existing public KeyQuest Studio contact address unless the owner specifies another address.
- Keep legal and support copy available in English and Hebrew when the app's primary audiences use both languages.
